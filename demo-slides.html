Architecture

Kiến trúc đơn giản, không over-engineer

# Data flow
upload_file()
→ extract_text(file) # PDF/DOCX/TXT
→ truncate if > 50k chars
→ session_state["doc_context"]

chat_input()
→ build_prompt(ctx, history, q)
→ _call_llm(system, user_prompt)
→ render with st.chat_message

File structure

app.py ← Streamlit UI
src/tutor.py ← core logic
extract_text()
build_prompt()
chat()
tests/test_tutor.py ← 13 unit tests
Không dùng RAG Prompt injection TDD
AI Integration

AI chạy thật trong mọi flow

Groq API · LLaMA 3.3 70B Versatile · ~1–2s response

🧠

Curriculum-aware prompt

System prompt hardcode domain (LLM, LangChain, Agents, RAG, Python) — AI không trả lời lạc đề.

📄

Document-in-prompt

Toàn bộ file tài liệu inject thẳng vào system prompt. Đơn giản, nhanh, không cần vector store.

🔁

Multi-turn memory

Chat history được giữ trong session state và đưa vào mỗi prompt — AI nhớ context cuộc trò chuyện.

# System prompt — adaptive + structured output
"Khi giải thích, luôn theo cấu trúc: 1. Giải thích ngắn gọn 2. Ví dụ code 3. Câu hỏi kiểm tra"
"Nếu câu hỏi mơ hồ → hỏi lại: 'Bạn đang bị stuck ở điểm nào cụ thể?'"
